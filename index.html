⚙️ Integrasi Google Sheets & Deployment

Panduan praktis menghubungkan backend Google Apps Script dan mempublikasikan aplikasi.

🔗 Pengaturan Webhook URL Google Apps Script

Masukkan URL Web App hasil deploy Google Apps Script Anda di sini:

Kode Google Apps Script (Code.gs) 
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    
    // Auto-create header if empty
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(["Nama Anak", "Tanggal", "Aktivitas", "Skor"]);
    }
    
    sheet.appendRow([
      data.nama || "Anak PAUD",
      data.tanggal || new Date().toLocaleString("id-ID"),
      data.aktivitas || "Kuis",
      data.skor || 0
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({"result": "success"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(error) {
    return ContentService.createTextOutput(JSON.stringify({"result": "error", "message": error.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

📌 Panduan Deployment & Hosting Free:

1. Setup Google Spreadsheet:

  1. Buka Google Sheets baru & klik Ekstensi -> Apps Script.
  2. Hapus isi file Code.gs lalu tempelkan kode di atas.
  3. Klik Terapkan (Deploy) -> Terapkan Sebagai Aplikasi Web.
  4. Atur Akses (Who has access) menjadi "Siapa Saja" (Anyone).
  5. Salin URL Web App dan tempelkan pada kolom URL di atas!

2. Deployment Ke GitHub Pages:

  1. Buat repository baru di github.com (misal: mpi-buah-paud).
  2. Upload file index.html ini ke repository tersebut.
  3. Masuk ke menu Settings -> Pages.
  4. Pada bagian Branch, pilih main / master dan simpan (Save).
  5. Website Anda aktif secara instan pada tautan https://username.github.io/mpi-buah-paud.
